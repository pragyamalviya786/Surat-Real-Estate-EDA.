# Surat Real Estate EDA

This project focuses on **Exploratory Data Analysis (EDA)** of Surat real estate data to understand property trends, pricing patterns, and important features affecting real estate values.

The analysis was performed using Python libraries such as **Pandas, NumPy, Matplotlib, and Seaborn** for data cleaning, preprocessing, visualization, and extracting insights from the dataset.

## Key Tasks Performed
- Data Cleaning and handling missing values
- Exploratory Data Analysis (EDA)
- Feature understanding and correlation analysis
- Visualization of property prices, area, and location trends
- Comparing cleaned and uncleaned datasets

## Files Included
- `EDA.ipynb` → Jupyter Notebook containing complete analysis
- `surat_uncleaned.csv` → Raw dataset
- `surat_cleaned_final.xlsx` → Cleaned dataset

This project helps in understanding the Surat real estate market and demonstrates practical data analysis and visualization skills.
